# cone.cc

## Platform
Web; static personal blog deployed to conechan.pages.dev.

## Stack
Astro, React islands, Apps SDK UI and Tailwind CSS. User explicitly requested this migration and deployment.

## Product purpose
Read and browse the existing Chinese articles, organized chronologically and by their original categories. Preserve the author's identity, original article contents, images and dated URLs.

## Evidence
The original `_posts/`, `img/`, `about.md`, `_config.yml` and templates are retained as migration inputs. The source contains writing about technology, travel, piano and daily life. Do not invent biography, articles or publication dates.

## Constraints
Preserve `/:year/:month/:day/:title`, `/archive/`, `/about/`, `/img/`, favicon and Atom feed. Keep Markdown and embedded HTML. Adapt old Liquid highlight blocks during rendering. No change to cone.cc DNS is authorized by the pages.dev deployment request.

## Brand commitments
Latest user direction: reference https://maintao.com/ and use a complete single-column chronological page instead of a fixed Codex sidebar. Keep restrained neutral controls. The site remains cone.cc, not an OpenAI-branded product.
